Common Issues & Solutions
⚠️ Popup Won't Open?
1. Install Pera Wallet browser extension
2. Disable popup blockers for this domain
3. Check console for CORS errors (F12)
4. Ensure page is served on localhost/HTTPS
⚠️ peraWallet is undefined?
1. Script hasn't loaded yet - use event listeners
2. Check CDN link is accessible
3. Check network tab for 404 errors
4. Hard refresh (Cmd+Shift+R / Ctrl+Shift+R)
⚠️ Wrong Network?
1. Use testnet for development
2. Fund testnet account at dispenser.algorand.org
3. Switch network before connecting wallet
